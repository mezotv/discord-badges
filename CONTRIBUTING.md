## Contributing

Thank you for contributing to **Discord Badges**!

### How to Contribute

1. Fork the repository and create a new branch for your changes.
2. If you are adding or updating a badge:
   - Add/update the badge assets in the appropriate folder under `assets/`.
   - Update both `README.md` and `data/badges.json` with the badge details, flags, and descriptions.
3. Run the validation test suite locally:
   ```bash
   npm test
   ```
4. Ensure all tests pass and open a Pull Request.

You can also find a list of contribution ideas on our [Issues](https://github.com/mezotv/discord-badges/issues) page.
